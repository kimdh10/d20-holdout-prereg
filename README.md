# d20-holdout-prereg
Preregistered holdout for "Anomaly localizers miss absent parts that look normal in place".

code and the job scripts (lock_sha256 7cbd37f9c884...). The Real-IAD Variety holdout
(32 categories, camera 1) is opened only after this commit. Code will be released with the paper.
